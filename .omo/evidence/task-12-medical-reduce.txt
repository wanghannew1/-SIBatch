KEY DESIGN — 医保属地解析
--------------------------
reduce_records has NO medical_location column. Per spec, each person's
医保参保属地 is resolved by looking up enroll_records by id_card:

  SELECT medical_location FROM enroll_records WHERE id_card = ?
  ORDER BY id DESC LIMIT 1

Routing: take the code prefix before the first '-'; if it startswith
'2299' -> 省医保减员.xls, otherwise -> 市医保减员.xls.
If no enroll record matches (or medical_location is empty), the record
defaults to 市医保减员.xls (documented fallback; not hit by the QA
fixture, which has an enroll match).
